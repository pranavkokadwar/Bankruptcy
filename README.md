# Bankrupcy-Project
# 🏦 Bankruptcy Prediction App (Streamlit + Logistic Regression)

This web app predicts whether a company is likely to **go bankrupt** or remain **financially healthy**  
based on key financial indicators.

## 🚀 Live App
[Click here to open the app](https://bankruptcy-efbifczu6udsj3dxwpwc79.streamlit.app/)

## ⚙️ Tech Stack
- Python
- Scikit-learn
- Streamlit
- Pandas
- NumPy

## 📦 Installation (Local)
```bash
pip install -r requirements.txt
